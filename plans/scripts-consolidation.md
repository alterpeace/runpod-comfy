# Scripts Folder Consolidation Plan

## Goal
Reorganize the flat `scripts/` folder (45 scripts) into 6 category subdirectories and update all 88+ cross-references across the codebase.

## Proposed Directory Structure

```
scripts/
├── build/     (16) — Build, deploy, run, test, frontend, tunnel, node deps
├── models/    (6)  — Model download and install
├── invoke/    (6)  — Workflow invocation, debugging, verification
├── storage/   (6)  — Upload, sync, S3, output management
├── diag/      (8)  — Diagnostics, checks, patches, preflight
└── gpu/       (3)  — Local GPU/CDI setup
```

## Critical Cross-Directory Functional Calls

Only **2 cross-directory calls** exist (both from `run_local.sh`):

| Caller | Callee | Old path | New path |
|---|---|---|---|
| `build/run_local.sh` | `gpu/fix_local_gpu_cdi.sh` | `$SCRIPT_DIR/fix_local_gpu_cdi.sh` | `$SCRIPT_DIR/../gpu/fix_local_gpu_cdi.sh` |
| `build/run_local.sh` | `gpu/gen_gpu_compose_override.sh` | `$SCRIPT_DIR/gen_gpu_compose_override.sh` | `$SCRIPT_DIR/../gpu/gen_gpu_compose_override.sh` |

All other intra-script calls stay within the same directory (models/, gpu/, build/).

## `$SCRIPT_DIR/..` → `$SCRIPT_DIR/../..` Changes

Every shell script that computes `PROJECT_ROOT` or `PROJECT_DIR` via `$SCRIPT_DIR/..` needs to become `$SCRIPT_DIR/../..` since scripts are now one level deeper. Affected scripts:

- `build/build.sh`, `build/deploy.sh`, `build/run_local.sh`, `build/run_runpod.sh`, `build/run_frontend.sh`, `build/test_local.sh`, `build/update_custom_nodes.sh`, `build/collect_custom_node_deps.sh`
- `models/install_ltx23.sh`, `models/install_ltx25.sh`, `models/download_ltx25_runpod.sh`
- `storage/sync_to_runpod_s3.sh`
- `gpu/setup_local_gpu.sh`
